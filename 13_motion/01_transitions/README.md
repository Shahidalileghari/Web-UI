# Transitions, Animation, and Reduced Motion

## Learning objectives
# CSS Transitions and Motion

## Goal
Use motion to clarify state changes without making the interface distracting or uncomfortable.

## Key concepts
- Animate meaningful properties and keep durations restrained.
- Prefer transform and opacity for many animations.
- Respect `prefers-reduced-motion`.
- Motion should never be the only way to communicate a state change.
