# Forms and Native Validation

## Goal
Build forms that clearly label inputs, expose errors, and use browser-native validation where appropriate.

## Key concepts
- Every input needs a programmatic label.
- Use the correct input type and autocomplete hint.
- `required`, `minlength`, and `type=email` provide baseline constraints.
- Client-side validation improves UX; server-side validation is still required in real applications.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction

## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
