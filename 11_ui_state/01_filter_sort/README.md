# UI State, Filtering, and Sorting

## Goal
Derive what the user sees from data and current controls, rather than manually patching individual DOM nodes.

## Key concepts
- Keep a source data array as the canonical state.
- Derive filtered/sorted output from state.
- Render with DOM APIs and `textContent`.
- Empty states should explain what happened and what the user can do next.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction
