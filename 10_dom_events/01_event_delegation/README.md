# DOM Rendering and Event Delegation

## Goal
Handle events efficiently when many similar interactive items exist.

## Key concepts
- Event delegation listens on a stable ancestor and inspects the event target.
- `closest()` helps identify the intended control.
- Use `textContent` for untrusted text.
- Keep the event target check narrow and explicit.
