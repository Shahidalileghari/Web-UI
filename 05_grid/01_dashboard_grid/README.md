# CSS Grid for Dashboard Layouts

## Learning objectives
# CSS Grid

## Goal
Use Grid for two-dimensional layouts where both rows and columns matter.

## Key concepts
- `grid-template-columns` defines track sizing.
- `minmax()` lets tracks grow while respecting minimums.
- `repeat(auto-fit, minmax(...))` supports responsive card collections.
- Grid and Flexbox can be combined in the same component.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

- `styles.css`: visual system and responsive behaviour
