# Flexbox for Navigation and Toolbars

## Learning objectives
# Flexbox Layout

## Goal
Use Flexbox for one-dimensional layout: distributing and aligning items along a row or column.

## Key concepts
- `justify-content` distributes items along the main axis.
- `align-items` aligns items along the cross axis.
- `gap` creates consistent spacing.
- `flex-wrap` and `min-width: 0` help prevent overflow.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

- `styles.css`: visual system and responsive behaviour
