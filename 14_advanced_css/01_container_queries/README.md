# Container Queries and Advanced CSS

## Goal
Style a component according to the width of its container rather than only the viewport.

## Key concepts
- `container-type: inline-size` establishes an inline-size query container.
- Container queries make reusable cards adapt to where they are placed.
- `:has()` can style a parent based on descendants, but avoid unnecessarily complex selectors.
- Keep fallbacks and browser support in mind for the target audience.


## Run the lesson
