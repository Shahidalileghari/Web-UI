# Responsive and Mobile-First Design

## Goal
Design interfaces that adapt to viewport size, user preferences, and content length.

## Key concepts
- Start with a useful narrow-screen layout.
- Use fluid sizing with `clamp()` where appropriate.
- Add breakpoints when the content needs them, not for specific device names.
- Test at narrow widths, zoomed text, and landscape orientation.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour


## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
