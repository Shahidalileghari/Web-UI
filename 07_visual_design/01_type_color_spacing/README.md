# Typography, Colour, and Spacing

## Goal
Create a coherent visual language with a small, repeatable set of tokens.

## Key concepts
- Type scale establishes hierarchy.
- Line length and line height affect readability.
- Colour should communicate meaning and meet contrast requirements.
- Consistent spacing is usually better than many arbitrary values.
