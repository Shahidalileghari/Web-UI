# Accessibility and Keyboard-First UI

## Goal
Ensure the interface can be understood and operated with different input methods and assistive technologies.

## Key concepts
- Use native controls and meaningful labels.
- Preserve visible focus indicators.
- Do not use positive `tabindex` values to force focus order.
- Test keyboard-only navigation and zoom.
- Accessible design benefits everyone, not only screen-reader users.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction

## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
