# Front-End Performance Fundamentals

## Goal
Build interfaces that load quickly and remain responsive.

## Key concepts
- Avoid unnecessary large assets and layout shifts.
- Set image dimensions and use appropriate `loading` hints.
- Defer non-critical scripts when possible.
- Measure using browser performance tools rather than guessing.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction

## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
