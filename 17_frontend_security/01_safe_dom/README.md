# Front-End Security and Safe DOM Handling

## Goal
Avoid common client-side mistakes when rendering user-provided content.

## Key concepts
- `textContent` treats content as text; `innerHTML` parses markup and can create injection risks.
- Client-side validation is not a security boundary.
- Never place private API secrets in browser code.
- Treat URL parameters and stored browser data as untrusted input.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction
