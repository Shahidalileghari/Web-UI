# JavaScript for Browser Interfaces

## Goal
Connect user actions to interface behaviour while keeping the DOM and state predictable.

## Key concepts
- Select elements with stable selectors.
- Listen for events rather than using inline HTML handlers.
- Keep behaviour in JavaScript and presentation in CSS.
- Update text with `textContent` when inserting plain text.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction

## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
