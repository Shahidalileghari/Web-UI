# CSS Cascade and Design Tokens

## Goal
Understand how declarations win in the cascade and create reusable design tokens with CSS custom properties.

## Key concepts
- The cascade considers origin, importance, layers, specificity, and source order.
- Custom properties centralize colours, spacing, radii, and shadows.
- Prefer low-specificity, predictable selectors.
- Avoid using `!important` as a routine way to resolve conflicts.
