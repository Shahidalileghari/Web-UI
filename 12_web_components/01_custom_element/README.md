# Web Components and Custom Elements

## Learning objectives
# Web Components

## Goal
Create a small reusable UI component using the browser's native Custom Elements API.

## Key concepts
- Custom Elements define reusable HTML elements.
- Shadow DOM can isolate a component's internal markup and styles.
- Component APIs should be small and documented.
- Do not use Shadow DOM just because it exists; choose it when isolation helps.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour


## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
