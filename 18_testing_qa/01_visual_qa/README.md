# Testing, Debugging, and Visual QA

## Goal
Use a repeatable checklist to catch UI regressions across screen sizes, interactions, and accessibility basics.

## Key concepts
- Test content, interaction, keyboard flow, and layout—not only the happy-path screenshot.
- Inspect console errors and network failures.
- Test at multiple viewport widths and zoom levels.
- Automate stable behaviour, but retain human visual review.


## Run the lesson
Open `index.html` in your browser. For a more realistic workflow, use VS Code Live Server.

## Files
- `index.html`: semantic structure and sample content
- `styles.css`: visual system and responsive behaviour
- `app.js`: browser interaction

## Practice
Complete `exercises.md`. Test keyboard navigation and resize the browser before calling the lesson complete.
