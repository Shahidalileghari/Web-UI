# Semantic HTML and Page Structure

## Goal
Use HTML elements for their meaning, not just their default appearance. Semantic landmarks improve navigation for users, assistive technologies, and maintainers.

## Key concepts
- `header`, `nav`, `main`, `section`, `article`, and `footer` have different roles.
- Headings should describe the document outline.
- A page should have a useful title and language attribute.
- Use buttons for actions and links for navigation.
